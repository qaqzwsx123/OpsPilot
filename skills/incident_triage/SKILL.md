# 告警分诊 SOP

1. 识别告警级别、影响区域、关联设备和开始时间。
2. P1 在 5 分钟内确认影响范围，优先核查网络、心跳、供电与最近变更。
3. 无法恢复时创建高优工单，升级值班负责人，并持续同步进展。
4. 恢复后记录根因、处理动作、验证证据和复发预防项。
